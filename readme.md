
# HealthFit - Yoga \& Wellness Platform

## Project Overview

**HealthFit** is a web-based platform that encourages a balanced lifestyle through yoga, meditation, and wellness tools, built entirely using HTML, CSS, and Vanilla JavaScript. The app provides interactive guidance on yoga poses, meditation techniques, health advice, and includes a BMI calculator for personal health tracking. Its smooth, mobile-responsive design and traditional JS logic ensures accessibility and usability, without the need for external frontend frameworks.[^1][^2][^3][^4]

***

## Features

- **Home Page**: Overview and navigation to all modules.
- **Yoga Section**: Interactive exploration of yoga poses, searchable and filterable by category and difficulty.
- **Meditation Section**: Detailed guides on meditation styles (including Hindu, Mantra, TM, Third Eye, Chakra, and more).
- **BMI Calculator**: User-friendly calculator with instant category/advice and visual reference.
- **Contact/Form**: Reach out to the team, provide feedback, or ask for support.
- **About Page**: Information about the platform's vision and creators.
- **Responsive Design**: Optimized for desktops, tablets, and phones.
- **No Frameworks**: Pure vanilla JS; easy for learners and customizers.[^2][^3][^5][^4][^1]

## Folder / File Structure

```
├── index.html           # Landing/homepage
├── about.html           # About project
├── bmi.html             # BMI calculator
├── yoga.html            # Yoga pose explorer
├── mediation.html       # Meditation explorer
├── contact.html         # Contact form and info
├── error.html           # Error handler page

├── contact.css          # Contact form styling
├── yoga.css             # Yoga section styles
├── med.css              # Meditation section styling
├── utils.css            # Shared/util classes
├── script.js            # General interactivity and utility logic
├── utils.js             # Common JS helpers (e.g., toggles, shared UI logic)
├── yoga.js              # Yoga-specific filtering/search JS
├── page.js              # Per-page effect or navigation JS
├── contact.js           # Contact page scripting/validation
```

*All CSS/JS files are imported locally in each corresponding HTML file for modularity.*[^3][^5][^1][^2]

## How To Run

1. **Clone this repository** or download all files (maintaining the folder structure, especially for assets).
2. **Open `index.html`** in any modern web browser — all modules are linked from here.
3. **No Build/Installation Needed**: Since there are no frameworks or build tools, you just need a browser.
4. **Customize**: Edit individual JS/CSS/HTML files to change text, logic, or styling.
5. Optionally, open via a local server for full video/media support (recommended for best experience).
